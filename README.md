# Fricas_McNair
My current research for McNair I’m using Prof. Zografopoulos’ ICARUS Lab. My goal is to investigate how noisy, delayed, or manipulated sensor data affects TurtleBot3 navigation. This project uses ROS 2, which evaluates mapping, localization, and obstacle avoidance while exploring filtering, validation, and redundancy to improve reliability.
